Recommended order: web → Instagram the same evening → Facebook the next evening. If Monday is too full, Facebook can go the same evening right after Instagram; it must never go before the web text. Links carry ?utm_source=facebook&utm_medium=social&utm_campaign=<slug>.

Објава секоја недела

02 / 02

Every week as it will appear in the feed: the text from the calendar (social.fb.text_mk), the photo, and the link with UTM. Facebook shows a link card only on posts without photos: with photos, the link stays a blue link in the text. Each week shows both; the photo version is the default where a photo is suggested.

  1. Web first. Facebook reads the link preview the first time a link is shared and keeps it for weeks. Shared too early, it keeps an error.
  2. Check the card in the Sharing Debugger (link on each week) and press “Scrape again” after the article goes live or changes.
  3. Photos only with consent on file; no faces of minors; label AI images as such or don’t use them on Facebook.
  4. The link stays exactly as copied from the posting kit, with its UTM tags.
